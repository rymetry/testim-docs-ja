Testimは、コード、コードレス、または両方を組み合わせた方法で、回復力のあるエンドツーエンドテストを最速で作成できるプラットフォームです。

Testimでは、私たちも開発者でありテスターとして、品質の高いソフトウェアをより速くリリースすることを目指しています。安定したエンドツーエンドテストを書くことがあまりにも困難だったため、Testimを構築しました。私たちは、AIベースの機能テスト自動化ソリューションを最初に構築しました。2014年後半のローンチ以来、毎日お客様と一緒に機能を追加し、品質を向上させ、ソリューションを進化させてきました。製品機能や最新のブログについての詳細は、[Testim.io](http://testim.io/) をご覧ください。

Testimは、安定したテストの高速作成と、チームが効率的にテストを拡張するのに役立つTestOpsツールを可能にする、フル機能のテスト自動化プラットフォームです。Testimは主に3つのユースケースに対応しています：

## 主要なユースケース

### Web およびモバイルテスト

アジャイル開発チームが顧客向けのモバイルおよびWebアプリケーションを迅速かつ効率的にテストするのを支援します。Testimは使いやすく、テストへの幅広い参加を可能にします。また、高度な柔軟性を備えているため、上級ユーザーはJavaScriptコードを挿入することで困難なテスト問題を解決でき、それらを簡単に再利用してテスト全体で共有できます。

詳細については、[Web とモバイルテスト](/docs/testim-automate) をご覧ください。

### Salesforce テスト

Testimの高速作成とAIを活用した安定性により、Salesforceのような動的なアプリケーションに最適です。Salesforceと統合する顧客向けアプリケーションを構築している場合、Testimはエンドツーエンドのワークフローをテストするための優れた選択肢です。

詳細については、[Salesforce テスト](https://help.testim.io/docs/salesforce-testing-overview) をご覧ください。

### モバイルアプリテスト

Testimは、デバイスとアプリケーションの管理を簡素化し、モバイルアプリケーションのテストをより簡単にします。ユーザーは、同じ機能とTestimエクスペリエンスを使用して、ローコードテストを迅速に作成できます。

詳細については、[最初のモバイルテストの作成](https://help.testim.io/docs/creating-your-first-mobile-test-in-testim-visual-editor) をご覧ください。
