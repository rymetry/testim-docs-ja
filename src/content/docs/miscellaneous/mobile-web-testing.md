モバイルデバイスエミュレーターでアプリケーションをテストする

アプリケーションはモバイルデバイスをサポートしていますか？\
Testim を使用して、（モバイル Web）アプリケーションがさまざまなモバイルプラットフォームとデバイスでスムーズに動作することを確認しましょう。

## はじめに

モバイル Web プロジェクトがなく、必要な場合は、お問い合わせください。

## モバイル Web テストの作成方法

モバイル Web テストの作成は、デスクトップ Web テストと同様に機能します。新しいテストを開始すると、デフォルトの iPhone 6 設定が表示され、編集できます。

![モバイル Web テストの作成手順を示す GIF アニメーション。 iPhone 6 設定を選択してデバイスエミュレーターモードでテストを開始する様子](/images/miscellaneous/mobile-web-testing/f90da78-Aug-10-2020_12-12-32.gif)

デフォルト設定を選択した後、デスクトップ Web で行ったようにテストの記録を続行します（記録ボタンをクリックすると、選択した設定でエミュレーターモードの Chrome が開きます）。\
背後では、ユーザーエージェントを変更しています（画面サイズを変更するだけではありません）。

## 異なるデバイスで実行する

異なるデバイスでの実行は[CLI](/docs/the-command-line-cli)を介して行われます。

:::note
すべての可能な設定は、設定ページですでに設定されています。追加の設定を追加することはできません。
:::

別のデバイスでテストを実行するには、--test-config パラメーターを使用して、解像度設定をテストしたいモバイル解像度に設定します。

:::note
異なる画面サイズの異なるデバイスで実行すると、適切な「要素までスクロール」ステップがない場合、テストが失敗する可能性があります。さまざまな画面サイズをサポートするために、テストにスクロールを追加する必要があります。デスクトップ Web と同様に、より高い解像度設定で動作する最小解像度で記録することをお勧めします。
:::

## 既知の制限事項

現在、モバイル Web テストには別のプロジェクトが必要です。\
モバイル Web テストは Chromium エミュレーターに基づいています。つまり、すべてのモバイル Web プロジェクトのすべての設定で、 Chrome のみがサポートされています。
