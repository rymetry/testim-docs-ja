特定の UI 操作を処理するための特別な手順

テストを作成する際、ユーザーインターフェース（UI）との対話を必要とするステップがあります。すべての UI 操作が同じように作成されるわけではありません。Web ページはますます新しい機能を追加しており、ほとんどの記録/再生ツールに課題をもたらしています。クリックの記録やフィールドへのテキスト入力は簡単ですが、他の UI 操作はより追跡が困難な場合があります。

このセクションは、自動スクロールやドラッグ&ドロップなど、より困難な UI 操作が適切に記録され、ビジュアルテストエディターで表現されることを確実にすることに専念しています。
