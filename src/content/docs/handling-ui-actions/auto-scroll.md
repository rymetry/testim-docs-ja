スクロール関連の不安定性を排除して安定性を向上させます

デフォルトでは、Testimはビューポートの外側にあるテスト内のページ要素に自動的にスクロールします。これによりテストの安定性が向上し、スクロール関連のエラーが劇的に減少します。

## 自動スクロールを無効にする

**テストステップの自動スクロールを無効にするには:**

1. **テストリスト > テスト**に移動します。
2. **テストライブラリ**からテストを開きます。
3. 自動スクロールを無効にしたいテストステップをクリックします。

![テストステップの選択](/images/handling-ui-actions/auto-scroll/29b7146-auto-scroll-step.jpg)

4. アクションメニューで**ステッププロパティを表示**をクリックします。

![ステッププロパティを表示](/images/handling-ui-actions/auto-scroll/af61ba7-show-step-properties-gear-icon.jpg)

5. **自動スクロールを無効にする**を選択します。

![自動スクロールを無効にする](/images/handling-ui-actions/auto-scroll/be07acd-disable-auto-scroll.jpg)
