テスト実行の結果を PDF レポートとしてエクスポートし、メールで送信できます。レポートには以下の 3 つのバージョンがあります:

* **失敗ステップのスクリーンショット（推奨）** - 失敗したステップのスクリーンショットのみが含まれます。これにより、問題を迅速に特定できます。
* **すべてのスクリーンショット** - テスト内のすべてのステップのスクリーンショットが含まれます。
* **スクリーンショットなし** - スクリーンショットは含まれません。

レポートには以下の要素が含まれます:

* **テスト詳細** - テストの名前、説明、および基本詳細（プロジェクト、ブランチ、OS、実行者、開始/終了時刻、結果 ID）。
* **実行結果** - テスト結果サマリー（テストが成功または失敗したかの表示、テスト実行時間、実行設定情報（テストのベース URL、ターゲットデバイス、アプリケーション名））。
* **全体サマリー** - 成功、失敗、スキップ、警告を生成したステップの割合を表示します。
* **テストステップ** - テストステップとその結果のリスト。リストには、生成時のレポート設定に応じてスクリーンショットが含まれる場合があります。

:::note{title="Turbo モードが有効な実行"}
実行で Turbo モードが有効になっている場合、ステップ遅延と特定のアーティファクトをスキップしてテスト実行を加速するため、レポートには表示されません。ただし、これらは失敗した実行では利用可能です。
:::

## テスト画面からテストレポートを生成する

**テスト画面からレポートを生成するには:**

1. テスト実行後、テスト画面で 3 点メニューをクリックし、**PDF 実行レポートを生成**を選択します。

   ![テスト画面の PDF レポート生成メニュー](/images/results/test-run-pdf-report/1ff2d09-2024-08-08_16-38-55.png)
2. 以下のいずれかを選択します:

   ![PDF レポートの出力オプション選択画面](/images/results/test-run-pdf-report/fb19aab-2024-08-08_16-40-29.png)

   1. **失敗ステップのスクリーンショット（推奨）** - 失敗したステップのスクリーンショットのみが含まれます。これにより、問題を迅速に特定できます。
   2. **すべてのスクリーンショット** - テスト内のすべてのステップのスクリーンショットが含まれます。
   3. **スクリーンショットなし** - スクリーンショットは含まれません。
3. **生成**をクリックします。\
   数分後、レポートをダウンロードするためのリンクが記載されたメールが届きます。

   2. **すべてのスクリーンショット** - テスト内のすべてのステップのスクリーンショットが含まれます。

3. **生成**をクリックします。\
   数分後、レポートをダウンロードするためのリンクが記載されたメールが届きます。
