コンソールログには、システムの確認、エラー、通知情報が含まれます。テスト実行中、コンソールログはテスト結果の一部として表示されます。コンソールログは、ステップレベルまたはテストレベルで表示できます。

## ステップレベルでのコンソールログの表示

:fa-arrow-right: **ステップのコンソールログを表示するには:**

1. テストを実行します。
2. メインメニューで**実行**をクリックします。
3. 関連する実行をクリックします。
4. **実行**画面で、関連するテストをクリックします。\
   テストが表示され、実行されたステップが成功または失敗としてマークされます。
5. 関連するステップの**スクリーンショットを表示**ボタンをクリックします。
6. **コンソールログ**タブをクリックします。
7. 各ステップで取得したいログ詳細のレベル(verbose、error、warning、またはinfo)でフィルタリングしたり、ログテキストに一致する文字列を入力してフィルタリングしたりできます。

> 📘
>
> 画面の左右の矢印をクリックすることで、前後のステップのリクエスト結果を表示できます。

![ステップレベルのコンソールログ画面](/images/results/network-logs-copy/63aeaeb-consoletest.gif)

## テストレベルでのコンソールログの表示

テスト全体の集約されたコンソールログを一箇所で表示できます。コンソールログには、テスト実行中に生成されたログが表示されます。

:fa-arrow-right: **テストのコンソールログを表示するには:**

1. エディタまたはCLIからテストを実行します。
2. メインメニューで**実行**をクリックします。
3. 関連する実行をクリックします。
4. **実行**画面で、関連するテストをクリックします。
5. 横3点メニューをクリックし、**コンソールログを表示**をクリックします。
6. 各ステップで取得したいログ詳細のレベル(verbose、error、warning、またはinfo)でフィルタリングしたり、ログテキストに一致する文字列を入力してフィルタリングしたりできます。

![テストレベルのコンソールログ画面](/images/results/network-logs-copy/2c4ec40-consollog.gif)
