ビジュアル検証ツールは、ベースラインと現在のテスト実行を比較して、UI の変更やレイアウトの問題を検出します。

Testim は以下のビジュアル検証統合を提供しています:

- [Applitools](/docs/visual-validation)
- [LambdaTest SmartUI](/docs/lambdatest_integration)
