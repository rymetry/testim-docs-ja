同じパラメータでローカル再実行オプションを使用すると、**過去のテスト実行のパラメータデータに基づいてローカルでテストを実行**できます。これらのパラメータが利用できない場合でも、元のテスト実行結果に保存されたデータを使用することで克服できます。

> 📘 注意
>
> このオプションは、既存の結果ID(エディタまたはテスト実行ページ経由)が存在する場合に利用できます。

:fa-arrow-right: **同じパラメータでテストをローカル再実行するには:**

1. **テストエディタ**または**テスト実行**画面で完了したテストに移動します。
2. **再生メニュー**(テストエディタ)をクリックするか、**テスト実行を右クリック**(テスト実行)して、**同じパラメータでローカル再実行**オプションを選択します。\
   ![同じパラメータでローカル再実行のスクリーンショット](/images/test-execution/rerun-locally-with-the-same-params/09763c4-c367a60-rerunlocally.png)

> 📘 ベースURL
>
> 選択したテスト実行で使用されたベースURLは、「同じパラメータでローカル再実行」オプションで使用されます。セットアップステップのベースURLは、特定のテスト実行でオーバーライドされている可能性があります。ベースURL設定の詳細については、[ベースURL](/docs/base-url)を参照してください。
