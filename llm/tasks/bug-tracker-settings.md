Failed tests and bugs can be easily reported to your bug/issue tracking system. Testim integrates with popular bug tracking systems, enabling one-click publishing of issues. The issue will be created in the bug tracking system along with detailed description and a screenshot of the bug.

> 📘 This is a pro feature
>
> This feature is only open to projects on our professional plan. To learn more about our professional plan, click [here.](https://www.testim.io/pricing/)

There are various ways to report a bug/issue to the tracking system:

- As part of the [Tagging failed runs with failure types](/docs/results/tag-remote-runs-failures) process you can create an issue by clicking the **Create issue** link.

![](/images/bug-tracker-settings/bug-tracker-settings/78599fb-tagtestwithcreateissue.png "tagtestwithcreateissue.png")

- As part of the [Testim Chrome Extension](/docs/testim-extension/testim-extension-overview) tool you can capture the issue as a [Screenshot](/docs/testim-extension/testim-extension-capture-screenshot) or as a [Video & Bug Scenario](/docs/testim-extension/testim-extension-capture-video-bug-scenario)  and then click **Publish**.

![](/images/bug-tracker-settings/bug-tracker-settings/23ee812-publishbug.png "publishbug.png")

Testim can be connected to the following bug tracking systems:

- [Connecting Testim to Jira](/docs/bug-tracker-settings/connecting-testim-to-jira)  
- [Connecting Testim to Trello](/docs/bug-tracker-settings/connecting-testim-to-trello)
- [Connecting Testim to Slack](/docs/bug-tracker-settings/connecting-testim-to-slack)
- [Connecting Testim to Github](/docs/bug-tracker-settings/connecting-testim-to-github)
