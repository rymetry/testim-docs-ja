Keyboard shortcuts for quicker and easier test authoring

Testim has a set of shortcuts you can use to speed up your test authoring. Using these shortcuts will allow you to add various validations during test recording.

| Action Name                                                              | Windows           | Mac               | Available in |
| :----------------------------------------------------------------------- | :---------------- | :---------------- | :----------- |
| [Add Hover Step](https://help.testim.io/docs/hover-step)                 | Alt + H           | Option + H        | Editor + AUT |
| [Validate element text](/docs/validations/validate-element-text)                       | Alt + V           | Option + V        | Editor + AUT |
| [Validate element visible](/docs/validations/validate-element-visible)                 | Alt + L           | Option + L        | Editor + AUT |
| [Add custom validations and actions](/docs/validations/custom-code)                    | Alt + J           | Option + J        | Editor       |
| [Add new group](https://help.testim.io/docs/groups#creating-a-group)     | Alt + G           | Option + G        | Editor       |
| Save test                                                                | Ctrl + S          | Cmd + S           | Editor       |
| Create new test                                                          | Alt + N           | Option + N        | Editor       |
| [Validate Element Visualization](/docs/visual-validations/validate-element-visualization)     | Alt + E           | Option + E        | Editor + AUT |
| [Validate Viewport Visualization](/docs/visual-validations/validate-viewport-visualization)   | Alt + P           | Option + P        | Editor       |
| [Validate Full-page Visualization](/docs/visual-validations/validate-full-page-visualization) | Alt + D           | Option + D        | Editor       |
| Select all (in lists)                                                    | Ctrl + A          | Cmd + A           | Editor       |
| [Toggle breakpoint](https://help.testim.io/docs/stop-pause-debug-tests)  | Ctrl + B          | Cmd + B           | Editor       |
| [Copy Step](doc:editing-your-tests#copying-a-step)                       | Ctrl + C          | Cmd + C           | Editor       |
| [Cut Step](doc:editing-your-tests#cutting-a-step)                        | Ctrl + X          | Cmd + X           | Editor       |
| [Paste Step](doc:editing-your-tests#pasting-a-step)                      | Ctrl + V          | Cmd + V           | Editor       |
| [Delete Step](doc:editing-your-tests#deleting-steps)                     | Delete, Backspace | Delete, Backspace | Editor       |
| [Add extract value step](https://help.testim.io/docs/extract-text)       | Alt + X           | Option + X        | Editor       |
| [Wait For Element Visible](doc:wait-for#wait-for-element-visible)        | Alt + M           | Option + M        | Editor       |
| [Wait for element text](doc:wait-for#wait-for-element-text)              | Alt + T           | Option + T        | Editor       |
