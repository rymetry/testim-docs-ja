## Creating a new folder

:fa-arrow-right: **To create a new folder:**

1. In the Shared Steps Library screen, click the **New Folder** button.

![3704](/images/test-management/managing-shared-steps-and-folders/2d7c63e-Testim_056c.png "Testim 056c.png")

The **New Folder** window opens.

![](/images/test-management/managing-shared-steps-and-folders/ad17465-Testim_042_r.png)

2. In the **New name** field, enter the name of the folder.

> 📘 The name of the new folder must not be the same as any other folders that already exist in this project.

3. Click **OK**.\
   The folder is created.

![1402](/images/test-management/managing-shared-steps-and-folders/c4eaf28-Jan-28-2021_13-44-46.gif "Jan-28-2021 13-44-46.gif")

## Moving shared steps/folders to folders

By default, new shared steps are placed in the root folder. You can move shared steps and folders into other folders.\
:fa-arrow-right: **To move an item to a folder:**

1. Click on the shared step or folder name to select it.

> 📘 You can select multiple shared steps and/or folders by holding down the ctrl/cmd key and then clicking on each of the desired shared steps and folders.\
> You can also select all of your shared steps or folders by holding down the ctrl/cmd key + A on the keyboard.

2. Click the **Move to folder** icon (or right-click on the shared step or folder name and choose **Move to folder** from the right-click menu).

![3697](/images/test-management/managing-shared-steps-and-folders/e69ad9d-Testim_058a.png "Testim 058a.png")

The **Move To** window opens.

![](/images/test-management/managing-shared-steps-and-folders/9b7bee5-Testim_059_r.png)

3. Click on the target folder.

> 📘 If the target folder doesn't yet exist, you can create it now by clicking on the **New Folder** icon (bottom left of the window), entering the new folder's name, and clicking OK.

4. Click **Select**.\
   The items are moved to the selected folder.

![640](/images/test-management/managing-shared-steps-and-folders/3c7a06c-Jan-28-2021_13-54-14.gif "Jan-28-2021 13-54-14.gif")

## Renaming folders

You can rename folders in the Shared Steps Library screen.\
:fa-arrow-right: **To rename a folder:**

1. Click on the folder name to select it.
2. Click the **Rename** icon (or right-click on the test or folder name and choose **Rename** from the right-click menu).

![3697](/images/test-management/managing-shared-steps-and-folders/af0d84c-Testim_058b.png "Testim 058b.png")

The **Edit Name** window opens.

![](/images/test-management/managing-shared-steps-and-folders/e01dde7-Testim_060_r.png)

3. In the **New name** field, enter the new name of the file or folder.
4. Click **OK**.\
   The renamed file or folder can be viewed in the Shared Steps Library.

## Deleting folders

You can delete a folder or multiple folders through the Shared Steps Library screen.\
:fa-arrow-right: **To delete folders:**

1. Click on the folder name to select it.

> 📘 You can select multiple folders by holding down the ctrl/cmd key and then clicking on each of the desired folders.

2. Click the **Delete** icon (or right-click on the test or folder name and choose **Delete** from the right-click menu).

![3697](/images/test-management/managing-shared-steps-and-folders/fd63935-Testim_058c.png "Testim 058c.png")

The **Delete** confirmation window opens.

![](/images/test-management/managing-shared-steps-and-folders/14401e7-Testim_061_r.png)

3. Click **Delete**.\
   The folder/s are deleted.
