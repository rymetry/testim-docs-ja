Connecting Testim to Github

GitHub integration allows you to report bugs in Github Issues section straight from Testim. All the relevant bug info will be automatically populated.
To Connect Testim to Github:

  1. Go to Settings > Bug Tracker.
  2. Click the Github logo.
  3. Click the Log in link.
