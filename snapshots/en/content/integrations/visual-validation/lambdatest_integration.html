LambdaTest SmartUI integration

LambdaTest SmartUI is a visual validation tool that tests your web app’s UI across devices and highlights visual differences or layout issues, such as overlapping text, broken images, or incorrect spacing. Integrate LambdaTest with Testim to automate catching visual regressions.

Before you start

Before integrating LambdaTest with Testim, make sure you have the following:

  • Admin rights both in LambdaTest and Testim.

  • A project on our professional plan.

You'll also need need the following details from LambdaTest:

  • Username.

  • Access key.

  • Project token.

To learn how to get these details, check out LambdaTest's guide (opens in new tab).

Integrate LambdaTest SmartUI

You can start with LambdaTest as your first visual testing provider or switch to LambdaTest from another provider.

In either case, follow these steps:

  1. Go to Settings > Integration > Visual testing.

  2. Select login in the LambdaTest pane.

  3. Enter your Username, Access key and Project Token from LambdaTest.

  4. Select Connect.

Now you're using LambdaTest Smart UI as a visual testing provider, and you're ready to create or reuse baselines:

  • If this is the first visual testing provider you integrated: Design and run your first test to create baselines for detecting regressions.

  • If you switched providers: The first time you switch providers, Testim will automatically run tests to record new baselines. If you switch providers again, Testim will reuse your existing baselines.
