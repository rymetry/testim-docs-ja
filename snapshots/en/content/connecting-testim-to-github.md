# Connecting Testim to Github

GitHub integration allows you to report bugs in Github Issues section straight from Testim. All the relevant bug info will be automatically populated.\
:fa-arrow-right: **To Connect Testim to Github:**

1. Go to **Settings > Bug Tracker**.
2. Click the **Github** logo.
3. Click the **Log in** link.\
   The following notice is presented:

![572](https://files.readme.io/d04116b-github1.png "github1.png")

The following notice is presented:

![931](https://files.readme.io/7aa9766-github2.PNG "github2.PNG")

4. Click **Sign in** at the top of the screen and log in to your Github account.
5. After logging in, click **Configure**.

![1048](https://files.readme.io/b8b4322-github3.png "github3.png")

6. Specify where to install Testim.io by clicking the relevant account.

![654](https://files.readme.io/85799b1-github4.PNG "github4.PNG")

7. Click **Install**.

![575](https://files.readme.io/66d3537-github5.PNG "github5.PNG")

At this point the Testim Visual Editor is opened in the Settings > CLI screen.\
8\.	Go to **Settings > Bug Tracker** screen and click **Github**.\
9\.	Make sure the "You are logged in" message is displayed.

![392](https://files.readme.io/c4190f2-github6.PNG "github6.PNG")
