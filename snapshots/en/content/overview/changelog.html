Sealights test stage integration

Improved - June 2025

We've added support for custom team stage names to the Sealights integration to both CLI and Scheduler. You can use --sealights-test-stage [sealights-test-stage-name] to specify custom test stage names in commands. Or just enter your custom test stage name in the Scheduler configuration screen.

Hidden Parameters have moved to Resources!

Improved - April 2025

From now on, you can find and manage hidden parameters in the new Resources tab. This move also includes new capabilities to manage your hidden parameters and makes is simpler to create tests.

Secrets

Added - April 2025

We're excited to introduce Secrets in Testim: an easy and secure way to manage sensitive values in your automated tests.

Enhanced Merge Control

Improved - February 2025

We have improved our branch merging feature to allow greater control of what is being merged. In the merge branch dialog, we have added a checkbox at the top of the of added and changed tests list. This checkbox allows you to select and deselect all underlying tests with one click.

Fasten Your Seatbelts! Optimized Process for Web Test Recordings

Improved - February 2025

TL;DR
If you have large and/complex applications and tests, this one is a game changer! We've optimized our web test recording process by implementing selective and conditional DOM cloning that avoids unnecessary duplicates, and handles DOM changes efficiently, resulting in faster performance for complex applications.

AND/OR operands for Labels

Improved - February 2025

When filtering lists based on Labels, it is now possible to select the operand that will be used as the filter.
