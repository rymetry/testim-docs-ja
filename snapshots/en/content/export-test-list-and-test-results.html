Export test list and test results

You can export your test results both from the Execution Runs view, Test Runs view, and Test List by clicking on the export button. Using the different filters available on each view, will create a modified export file according to the selected filters.

This is a pro feature This feature is only open to projects on our professional plan. To learn more about our professional plan, click here.

Export Test Results from Execution Runs View

→ To export test results from the Execution Runs view:

  1. Navigate to Runs > Execution Runs.

  2. Click the Advanced Filters button to filter the list of execution runs you want to export (See Execution Runs Screen)

  3. Click the Export to CSV button to download a CSV file of the execution runs.

Export Test Results from Test Runs View

→ To export test results from the Test Runs view:

  1. Navigate to Runs > Test Runs.

  2. Click the Advanced Filters button to filter the list of execution runs you want to export (See Test runs).

  3. Click the Export to CSV button to download a CSV file of the execution runs.

Export Test Results from Test List View

→ To export test results from the Test List view:

  1. Navigate to Test List > Tests.

  2. Click the Advanced Filters button to filter the list of execution runs you want to export (See Test runs).

  3. Click the Export to CSV button to download a CSV file of the execution runs.
