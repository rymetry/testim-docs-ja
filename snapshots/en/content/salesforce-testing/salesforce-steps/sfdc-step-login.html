Log in

Salesforce Step This is a Salesforce step.

The Log in step logs into Salesforce using the selected Persona. All Salesforce Steps, except the steps under the API Operations category, require you to be logged in to the Salesforce environment. → To add a Log in step:

  1. In the editor, add a step by clicking the + button.

  2. Under the Salesforce steps tab, click Common operations and select Log in step.

    3. The Log in step is added and the following Object properties is displayed.

  3. Under Select login persona, select the desired persona from the drop-down menu.

  4. If you cannot find the desired persona, create a new one by following the instructions in Creating a persona.

  5. When finished, click Save.
