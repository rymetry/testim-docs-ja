# View Local Connected Mobile Devices

The Local Devices section allows you to view all physical and virtual mobile devices connected to your Tricentis Mobile Agent (TMA). For more information on adding and managing mobile devices, see [Configure Tricentis Mobile Agent](https://help.testim.io/docs/configure-tricentis-mobile-agent)

## View Connected Local Devices

:fa-arrow-right: **To view connected devices:**

1. Click the **Mobile Devices** button from the main navigation menu.

![](https://files.readme.io/95bbf7b-devicemgmtmenu.png)

2. Select **Local Devices** from the top menu. Testim will display a list of local devices connected to your workstation.

![](https://files.readme.io/6f8b3e6-local_devices.png)

### Copying the device UDID

It is possible to easily copy the device UDID and use it, for example, to run a test on a specific device through the CLI.

:fa-arrow-right: **To copy a device UDID:**

1. Hover over the UDID.\
   A copy icon is displayed.

<Image align="center" src="https://files.readme.io/5fb74a4-UDID.png" />

2. Click the copy icon.\
   The UDID is copied to the clipboard.
