VSTS and TFS integration

​

​In order to integrate your tests with VSTS/TFS, first you need to have docker installed on the VSTS/TFS agent.

Now, just follow these steps:

  1. Go to Build page

    2. ​2. Create a new build

    ​3. Select your repository

  2. Select empty job

  3. Add task

  4. Add Docker task

  5. Select Action: Run a Docker command

  6. Set the Command with the appropriate parameters, as described in the CLI page. Here is the basic command template.

    7. Copy 
    run --rm -v $(Build.BinariesDirectory):/opt/testim-runner testim/docker-cli --token <TOKEN> --project <PROJECT-ID> --grid <GRID-NAME> --report-file /opt/testim-runner/testim-sanity-$(Build.BuildId)-report.xml

    ​ Note: For the grid name, read here how to set up your grid.

  7. In order for VSTS/TFS to store, analyze and show the results, we generate a standard JUnitXMLReporter XML file.

    8. For VSTS/TFS to use the file you need to add a Publish Test Results task

  8. Select Test result format: JUnit

  9. Set the Test results files value, according to the "report-file" parameter in section 8 and set the

  10. Set the Search folder $(Build.BinariesDirectory)

  11. Save the build settings
