## 1. Scope overview

Tier C covers the long tail of M2 parity burn-down. Individual per-slug agent dispatch would run 53
independent agents for 82 entries — an average of 1.5 entries per agent, which has a prohibitive
orchestration overhead vs. the small amount of JA edits each agent actually performs. Wave 5 instead
batches slugs by **dominant drift pattern** so that a single mechanism script can enumerate candidate
edits across all same-pattern slugs with a uniform dry-run contract.

This inventory is the input to `scripts/bulk_wave5_fix.mjs` (prototype) — it catalogs every Tier C slug
by the most specific pattern that covers its actionable issues. Inconclusive / structural-cross entries
stay manual (subset flagged below).

`integrations/visual-validation/lambdatest_integration`.

### 3.3 Pattern C — `ja-extra-intro-paragraph` (8 slugs)

identical (EN `[paragraph → ordered-list]` vs. JA `[paragraph → paragraph → ordered-list]` or similar).
Root cause is a JA-added intro paragraph — usually a "説明:" lead-in — that EN does not have. Fix is
either delete the paragraph or merge it into the preceding / following block.

## 5. Wave 5 execution plan (proposed)

1. **Sub-wave 5.A — generic-english-residue (10 slugs)**
   - Mechanism: per-slug agent with `scripts/bulk_wave5_fix.mjs --pattern=generic-english-residue
     --slug=<slug>` reports the untranslated segment → human/agent rewrites the segment in JA.
   - Scope-per-agent: single slug, 1–2 segments.
2. **Sub-wave 5.B — url-verbatim (10 slugs)**
   - Mechanism: `scripts/bulk_wave5_fix.mjs --pattern=url-verbatim` auto-proposes link swaps from
     the `missingTokens` payload. Review diff → apply.
3. **Sub-wave 5.C — ja-extra-intro-paragraph (8 slugs)**
   - Mechanism: `scripts/bulk_wave5_fix.mjs --pattern=ja-extra-intro-paragraph` enumerates
     candidate paragraphs to delete/merge. Per-slug human review (paragraph content decides whether
     to merge or remove).
4. **Sub-wave 5.D — paired-missing-extra (11 slugs)** — per-slug agent (Wave 4 cadence).
5. **Sub-wave 5.E — structure-mismatch-missing-paragraph (5 slugs)** — per-slug agent.
6. **Sub-wave 5.F — alignment-inconclusive (8 slugs)** — investigate EN-side root cause first, then
   decide per-slug fix vs. baseline acknowledgement.
7. **Residual (1 slug)** — per-slug review.

## 6. Non-goals

- This plan does **not** apply any content fixes. Only the mechanism + inventory is in scope.
- `parity-baseline.json` is not modified.
- `snapshots/en/**` is not modified.
- The three prototyped patterns (A / B / C) are the **only** implementations in this PR; D / E / F /
  residual patterns remain deferred.
